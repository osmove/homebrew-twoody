# Homebrew tap for Twoody

[Twoody](https://www.twoody.com/) is a private AI assistant that runs on
your Mac: it answers and reads your documents with a model installed on
the computer.

```sh
brew install --cask osmove/twoody/twoody
```

The app then updates itself; `brew upgrade` is not needed for it. The
cask follows the releases published on downloads.twoody.com, checked by
their SHA-256.

Published by [Osmove](https://www.osmove.com/).
